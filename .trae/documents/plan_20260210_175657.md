I will turn the individual files we've created into a **runnable, testable MVP** right here on your machine. This allows you to verify the "Capture" and "Track" phases immediately without needing to set up Shopify or Make.com yet.

### 1. Create Local Demo Environment (`demo.html`)
- Build a standalone HTML file that **simulates a Shopify product page**.
- It will feature a mock product ("Red Floral Kurta") with variant selectors (Size S, M, L).
- **Size M will be "Out of Stock"** to trigger your "Notify Me" widget.
- This proves the frontend logic works: widget appearance, data capture, and user interaction.

### 2. Create Mock Backend Server (`server.js`)
- A simple Node.js server to replace Make.com for testing.
- **Serves the demo page** and your JS/CSS assets.
- **Listens for Webhooks**: It will receive the `notify_intent` and `oos_visit` payloads that your widget sends.
- **Logs Data**: You will see real-time logs in the terminal ("Received: Missed Revenue for Size M") instead of checking Google Sheets.

### 3. Documentation & Deployment Guide (`README.md`)
- **Quickstart**: One command to run the demo (`node server.js`).
- **Production Guide**: Step-by-step instructions to take these files and deploy them to a real Shopify store + Make.com + Google Sheets when you are ready.

### 4. Integration
- Connect the `size-signal.widget.js` and `size-signal.tracking.js` to this local server for testing.

**Outcome:** You will have a working local prototype. You can open a browser, click "Notify Me" on a fake out-of-stock product, and see the data appear in your terminal instantly.
