# SizeSignal

SizeSignal helps Shopify fashion brands identify lost revenue from out-of-stock sizes and receive weekly restock recommendations on WhatsApp.

## What this repository contains

- Product blueprint and clarified MVP scope
- Technical architecture for a no-code/low-code first launch
- Data schema and event model for out-of-stock demand tracking
- A 4-week execution plan to go from idea to pilot launch

## MVP promise

> "Know exactly which sizes to restock before you lose the sale."

The first version focuses on one sharp outcome:

1. Capture out-of-stock demand signals at variant level.
2. Convert signals into missed-revenue estimates.
3. Deliver weekly WhatsApp restock recommendations to founders.
